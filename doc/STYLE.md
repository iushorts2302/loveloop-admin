# Loveloop AI — 관리자웹 스타일 가이드 (STYLE.md)

> 버전 1.0 · 2026-05-31 · 대상: `loveloop-admin`
> 기반: 사용자웹과 동일 색/배경 시스템 + 데스크톱 도구 UI(단정함 우선)

---

## 0. 원칙

관리자웹은 **운영 도구**다. 사용자웹의 색·배경·글래스 GNB는 공유하되, 본문(테이블/리스트)은
도구로서 단정함을 우선한다. 트렌드 액센트(글래스/그라데이션)는 GNB·사이드바·대시보드 카드에만.

- 콘텐츠 자체보다 **안전·웰빙 보호 운영**이 콘솔의 목적
- 차별 기능: **웰빙 운영**(과몰입 모니터·넛지 정책) + **다크패턴 감사**(과금 UX 점검)

---

## 1. 레이아웃

```
┌──────────────────────────────────────┐
│  GNB (글래스, fixed)                   │  로고 · 환경 배지 · 역할 · 운영자
├────────┬─────────────────────────────┤
│        │  topbar (제목 + 액션)         │
│sidebar │ ─────────────────────────── │
│ 9메뉴  │  content (page 전환)         │
│ 236px  │                             │
└────────┴─────────────────────────────┘
```

데스크톱 우선(1280px+). 사이드바 236px + 본문 가변.

---

## 2. 색상 (사용자웹과 공유)

```css
--color-primary:#0066CC; --color-primary-dark:#4DA3FF;
--canvas:#FAFAFC; --surface:#FFFFFF; --surface2:#F5F5F7;
--ink:#1D1D1F; --t2:#5B5D62; --t3:#8A8C92;
--green:#1E8E4E; --warn:#B7791F; --red:#D70015;
```

배경: 사용자웹과 동일하게 옅은 메시 그라데이션(blue/green) + canvas.

---

## 3. 도구 UI 규칙 (단정함)

- **테이블/리스트**: 글래스·그라데이션 금지. 흰 배경 + `--line` 보더, hover 시 `--surface2`
- **상태 태그** `.tag`: green/warn/red/blue/gray — 얇은 보더 + 옅은 배경
- **mono**: ID·코드·시각은 monospace
- **카드 hover**(`.card.hov`): translateY(-1px) + primary 옅은 그림자 (대시보드 카드에만)

---

## 4. 트렌드 액센트 (허용 범위)

- **GNB**: 글래스 blur + 반투명
- **사이드바 active**: primary 좌측 보더 + `--primary-soft` 배경
- **대시보드 stat-value**: 그라데이션 텍스트 클립
- 그 외 본문은 솔리드 유지

---

## 5. 9개 페이지

| 페이지 | 경로 | 핵심 |
|---|---|---|
| 대시보드 | `dash` | KPI 4 + 활성 추이 + **웰빙 지표** + 활동 피드 |
| 콘텐츠·페르소나 | `content` | 페르소나 톤 가드레일 테이블 + 콘텐츠 승인 + 검수 규칙 |
| 안전 가드레일 | `safety` | 통제·집착 차단 사전 + 할루시네이션 가드 |
| **웰빙 운영** | `wellbeing` | 과몰입 코호트 모니터 + 넛지 정책 |
| **다크패턴 감사** | `darkpattern` | 과금 UX 점검 체크리스트(통과/주의) |
| 결제·환불 | `billing` | 결제 내역 + 쿨다운·상한 정책 + 환불 |
| 신고·검토 | `reports` | 신고 큐(영구삭제 별도 승인) |
| 사용자·권한 | `users` | 관리자 계정 + 미성년 보호 |
| 시스템 설정 | `sysset` | LLM·음성·가드레일·알림 |

---

## 6. 컴포넌트

- 버튼 `.btn` / `.primary` / `.green` / `.red` / `.sm`
- 토글 42×24px, ON primary
- 막대 `.bar` + `.bar-fill`(primary/green/warn/red)
- 감사 항목 `.audit-item`: pass(녹색 ✓) / fail(빨강 !)
- 배너 `.banner`: green/warn/blue

---

## 7. 안티패턴

- ❌ 테이블/리스트에 글래스·그라데이션
- ❌ 본문 텍스트에 primary
- ❌ 한 화면 5색 초과
- ❌ 강한 그림자 + 강한 보더 동시

---

## 8. 안전 운영 일관성

관리자웹은 사용자웹의 건강 설계를 **집행**한다.
- 페르소나 톤 검수에서 통제·집착·고립 대사 차단
- 다크패턴 감사로 정서 고조 결제·가챠·충전보너스·잠금과금 배제 확인
- 웰빙 운영으로 과몰입 코호트에 결제 대신 휴식·현실관계 격려 우선
- ⚠️ 웰빙 임계 수치·미성년 강화 상한은 운영 합의 필요(미확정)
